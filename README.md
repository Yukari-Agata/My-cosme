# My-cosme
コスメ管理用アプリケーションです。
想定する顧客：美容系配信者やコスメ集めが趣味で大量に化粧品を持っている人

## 機能一覧
- コスメの新規登録
- カテゴリ検索
- 価格帯検索

## ver1.1での追加内容
- 使い切りを削除ではなくリピあり・リピなしのフラグをつける論理削除に変更

## 今後追加予定の機能
- リピあり・リピなしリスト
- 全件検索をカテゴリごとに固まるように編集
- 使い切りを使い切りリストに保存(リピなし・リピありを保留したい場合に使うため)
- お気に入り機能
- 1軍、2軍や季節ごとに使うものなどグループを作れる機能

## 使用技術
- Java / Spring Boot
